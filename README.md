# Tramston Light Rail Scripts

## A showcase of notable scripts from the Roblox game Tramston Light Rail

The game Tramston Light Rail on Roblox is a project run by me from 2022 in order to learn programming and game development, which I am passionate about. This repository is for showcasing some of my scripts, not to be seen otherwise.
Game link if you want to see their working in practice: https://www.roblox.com/games/10029274361

## Next Stop Script

This script is responsible for calculating next stops on tram routes, and awarding players for stopping. Its functionality is:
* Showing player the next stop on the route
* Calculating distance (in meters) to the next stop
* Awarding player for stopping correctly
* Punishing player for moving before passengers have loaded
* Ending route at the last stop
